# 👑 BOYFRIEND PIIE - FB MESSENGER AUTOMATION 👑

**Professional FB Messenger Automation Tool with Streamlit UI**

## ✨ Features

✅ **User Authentication** - Secure login/register system
✅ **Cookie-based Automation** - Uses browser cookies for authentication
✅ **Multi-message Support** - Send multiple different messages in rotation
✅ **Encrypted Storage** - Cookies stored encrypted with Fernet
✅ **Beautiful UI** - Royal/King theme with gold accents
✅ **Real-time Logs** - Watch automation happen live
✅ **Telegram Notifications** - Get alerts when cookies are uploaded
✅ **Admin Panel** - Control panel for administrators
✅ **Streamlit Cloud Ready** - Deploy directly to Streamlit Cloud

## 🚀 Quick Start

### Local Development

```bash
# 1. Clone repository
git clone https://github.com/YOUR_USERNAME/messenger-automation.git
cd messenger-automation

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run Streamlit app
streamlit run streamlit_app.py
